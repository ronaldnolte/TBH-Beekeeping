# Interventions

An intervention is a record of something you **did** to a hive (as opposed to an inspection, which records what you **saw**).

## Add an intervention

1. Open the hive and choose the **Interventions** tab.
2. Tap **+ Add**.
3. Choose a **Type**:
   - Feeding
   - Treatment
   - Manipulation
   - Cross Comb Fix
   - 👑 Queen Replacement
   - Honey Harvest
   - Other
4. Set the **Date** (defaults to today).
5. Add **Notes** (for Queen Replacement the hint suggests queen source, markings and reason).
6. Tap **Save Intervention**.

## Viewing and editing

- The list shows the 3 most recent interventions; **View All (n)** expands it.
- Each type has its own colour tag. Tap a row for **Intervention Details** with **Edit** and **Delete**; in the list **✎** edits and **×** deletes (with confirmation).
- Only the apiary owner can add, edit or delete interventions.

## Queen Replacement and the mite chart

Interventions of type **Queen Replacement** appear as purple 👑 markers on the **Mite Load by Season** chart on the Varroa tab, so you can see whether a requeening coincided with a change in mite load (see `07-varroa-mite-tests.md`).
