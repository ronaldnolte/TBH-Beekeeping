# Inspections

An inspection is a dated record of what you observed in one hive.

## Add an inspection

1. Open the hive and choose the **Inspections** tab.
2. Tap **+ Add**.
3. Set the **Date** (defaults to today; you can back-date).
4. Tap one option in each group (details below), and add **Notes**.
5. Tap **Save Inspection**.

## Fields

| Field | Choices | Default |
|---|---|---|
| Queen Status | Seen, Eggs, Capped, Virgin, NO QUEEN, Q. Cells | unknown (none selected) |
| Brood Pattern | Solid, Good, Spotty, Poor | Good |
| Temperament | Calm, Moderate, Defensive, Aggressive | Moderate |
| Honey Stores | Abundant, Medium, Low, None | Medium |
| Pollen Stores | Abundant, Medium, Low, None | Medium |
| Notes | free text | — |

Meaning of the queen options: **Seen** = you saw the queen; **Eggs** = fresh eggs present; **Capped** = capped brood present; **Virgin** = a virgin queen; **NO QUEEN** = queenless; **Q. Cells** = queen cells present.

## Viewing the list

- The list shows your 3 most recent inspections; **View All (n)** expands it.
- Columns: Date, Queen (colour-coded: green = queen/laying evidence, pink = virgin, red = no queen or queen cells), Brood, Tmp (temperament), Hon, Pol, and Observations.
- Tap a row to open **Inspection Details**, which has **Edit**, **Delete** and **Close**.
- In the list, **✎** edits and **×** deletes (after confirmation).

Only the apiary owner can add, edit or delete inspections. People you have shared the apiary with can view them.
