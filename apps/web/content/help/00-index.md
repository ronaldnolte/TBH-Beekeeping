# BeekTools Help Library

BeekTools is a free beekeeping management app for hobby beekeepers. You keep a record of your **apiaries** (bee yards) and **hives**, log **inspections**, **interventions**, **mite tests** and **tasks**, check an hourly **inspection forecast**, and can ask the built-in **Ask AI** assistant beekeeping questions.

## Guidance for the AI assistant using this library

- Answer "how do I use the app" questions only from these documents. If something is not covered, say you are not sure and suggest the **feedback button** (envelope icon in the page header) rather than guessing.
- Use the exact button and screen names shown in **bold** in these documents.
- Beekeeping-practice questions (what to feed, when to treat) are not answered by this library; answer them from general beekeeping knowledge, as usual.

## Vocabulary

| Term | Meaning in BeekTools |
|---|---|
| Apiary | A location where you keep hives. Has a name, a location (postal code or GPS coordinates) and optional notes. |
| Hive | One colony/box setup inside an apiary. Has a type (Langstroth, Top Bar, etc.). |
| Bar | One top bar of a bar-style hive (Top Bar, Warré, etc.), shown as a coloured rectangle. |
| Snapshot | A saved picture of a hive's bar or box configuration at a point in time. |
| Inspection | A record of what you saw in a hive on one date. |
| Intervention | A record of something you did to a hive (feeding, treatment, requeening, etc.). |
| Mite test | A varroa test result (mites found out of bees sampled) compared with a seasonal threshold. |
| Owner | The person who created an apiary. Only the owner can change its data. |
