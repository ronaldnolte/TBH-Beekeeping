# Bar and Box Configuration

## Bar hives (Top Bar, Warré, Layens, etc.)

The hive screen shows a row of numbered bars (scroll sideways if there are many). **Tap a bar to change its status.** Each tap moves to the next status in this order, then loops:

**Inactive → Active → Empty → Brood → Resource → Follower board → Inactive**

| Status | Colour | Typical meaning |
|---|---|---|
| Inactive | dark gray | unused/not yet part of the colony's space |
| Active | cyan | actively worked bar |
| Empty | white | empty bar or empty comb |
| Brood | brown | brood comb |
| Resource | yellow | honey and/or pollen stores |
| Follower board | very dark gray | the follower board position |

A tap saves the new status to the hive immediately — there is no separate save button. A legend below the bars shows the colours.

### Snapshots

A **snapshot** is a saved copy of the current bar layout with the date and time.

- Tap **Capture** (camera icon) to save a snapshot of the layout as it is now.
- The **History** panel lists snapshots, newest first (3 shown; **View All (n)** shows the rest).
- Tap a snapshot to view that past layout. The bar view switches to **(History View)** and is read-only. Tap **Back to Latest** to return.
- Tap the **×** beside a snapshot to delete it (asks for confirmation).
- Changing the number of bars in **Edit Hive** saves a snapshot automatically.

Tip: change bars while you work, then tap **Capture** when you finish an inspection so the history shows how the colony changed over time.

## Langstroth hives (8- and 10-frame): the box builder

For Langstroth hives the configuration is a vertical stack of boxes between an **Outer Cover** at the top and a **Bottom Board** at the bottom. On the hive screen it is shown read-only; tap **Edit Hive** to change it.

In the **Parts Palette**:

- **8 / 10** toggle: frames per box. It applies to every box in the stack.
- **Deep (9⅝")**, **Medium (6⅝")**, **Shallow (5¾")** boxes.
- **Excluder**, **Slatted Rack**, **Inner Cover**, **Top Feeder**.
- A new part is added at the **top** of the stack.
- **Drag** a part to reorder; use its delete control to remove it.
- **Stats** shows the total stack height in inches.

Saving a changed box layout creates a snapshot automatically, so your history records when you added or removed supers.

The **Langstroth Lab** is an unsaved sandbox prototype of the builder; nothing in it is stored.
