# Apiaries

An apiary is a place where you keep hives. Every hive belongs to exactly one apiary.

## The apiary list screen

This is the screen you land on after logging in.

- **Select Apiary** dropdown: choosing an apiary opens it immediately. Your apiaries are listed under **My Apiaries**.
- **Show Shared** checkbox: adds apiaries other people have shared with you (see `10-sharing-and-mentors.md`).
- **⚙️ Manage Apiaries**: opens the management panel (button changes to **Done** while open).
- **My Upcoming Tasks**: your tasks across all hives (see `08-tasks.md`).
- **Ideas** opens the feedback roadmap; **Logout** signs you out. Admin users also see **Admin**.
- On wide screens, a small weather chip shows the current conditions for the selected apiary, coloured green/yellow/red by inspection score.

## Creating an apiary

1. Tap **⚙️ Manage Apiaries**, then **+ Create New Apiary** (or **+ Create First Apiary** if you have none).
2. Enter an **Apiary Name** (for example "Home Yard").
3. Set the **Location** (used for weather):
   - **Postal Code** tab: choose the country, then type the postal code. The app warns if the format looks wrong.
   - **Coordinates** tab: enter latitude and longitude. Choosing Ghana switches to this tab automatically, because postal codes are not supported there.
4. Optionally add **Notes** (access instructions, etc.).
5. Tap **Create Apiary**. A location is required — either a postal code or coordinates.

Supported countries for postal codes: Australia, Austria, Belgium, Bulgaria, Canada, Croatia, Czech Republic, Denmark, Estonia, Finland, France, Germany, Greece, Hungary, Ireland, Italy, Latvia, Lithuania, Luxembourg, Netherlands, New Zealand, Norway, Poland, Portugal, Romania, Spain, Sweden, Switzerland, United Kingdom, United States (and Ghana via coordinates). Any country can use coordinates.

## Editing, sharing and deleting

In **⚙️ Manage Apiaries**, each apiary has **Share**, **Edit** and **Delete** buttons.

- **Edit** changes the name, location and notes.
- **Delete** only works when the apiary has **no hives**. If it has hives, the app tells you how many and refuses. Delete or move the hives first.

## The apiary dashboard

Opening an apiary shows its hives as cards. The toolbar has:

- **← Apiaries** — back to the list
- **📊 View Forecast** — the hourly inspection forecast (`09-weather-forecast.md`)
- **🤖 Ask AI** — beekeeping assistant (`11-ask-ai.md`)

See `03-hives.md` for adding and managing hives.
